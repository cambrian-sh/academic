## Numbers worth citing (all vendor-reported; label as such)

- P2: ~5× test-time compute reduction at matched accuracy (Stateful
  GSM-Symbolic / Stateful AIME); +13%/+18% accuracy from scaling
  sleep-time; 2.5× amortized cost/query (Multi-Query GSM-Symbolic).
  Efficacy correlates with query predictability.
- B04: 42.5% Terminal-Bench, <200 lines, todo-list memory block +
  recursive summarization at 40k tokens.
- B05: 74.0% LoCoMo on gpt-4o-mini with plain files vs Mem0 68.5% graph.
- B06: recovery averages 11.2% vs 26.3% fresh (−57% rel); full action
  history in context is the *worst* setting (context pollution).
- B07: Sonnet 4.5 74.0%/$24.58 vs GPT-5 72.67%/$43.56; GLM-4.6 56.83,
  Kimi K2 55.13/$12.08; nano models collapse.
- B08: +14.1% task completion from the relevant skill; −6.5% when the
  model must also *select* it; Mini/Nano below capability threshold.
- B09: +21.1% rel trajectory-only, +36.8% rel (15.7pp abs) with verifier
  feedback; −15.7% cost, −10.4% tool calls on Terminal-Bench 2.0.
- B15: ~5× token reduction vs native session formats (Anthropic counter).
- B16: Anthropic leads memory *generation*; OpenAI trails except
  GPT-5.6-Sol; Kimi-K3 strong at repair; adherence led by GPT-5.6-Sol /
  Fable-5 (OpenAI edges Anthropic — the one split they win).

## What this changes for Cambrian

1. **Graph-signal skepticism now has industry legs (flagship honest
   limit).** B05 (flat files beat graph memory tools on LoCoMo) sits next
   to B8/Selective-Forgetting (graph loses to flat at matched budget).
   Two independent sources, same direction. Reproduction obligation
   stands, but the prior is now skepticism, not neutrality.
2. **Topic-10 instrument shelf is fuller.** B09 skill-learning numbers are
   the baseline our consolidation study must beat or match with
   principled gates; B08's use-vs-selection split maps onto arms;
   B10's (θ,C) formalization is the theory anchor — cite it.
3. **Methodology borrowings.** B07: fictional entities + SQL ground truth
   + cost tracking (template for future suites). B06: recovery-state
   evaluation (fresh-vs-dirty arms). B15: trajectory normalization
   precedent for row traces. B03: penalize extraneous tool calls in
   scoring — adopt in policy-asks if not already present.
4. **Policy-asks design.** B16: messy-vs-clean memory profiles and the
   generation-vs-usage split inform A2+ arms; the Sonnet-5
   deletes-legit-rule failure is an over-refusal analogue — taxonomy
   material. B13: adversarial-auditor + judge harness is the evaluation
   pattern to mirror (and its multi-turn reversion finding warns that
   single-turn policy probes under-test robustness).
5. **Novelty confirmation (gaps Letta leaves open).** No policy/
   authorization story (no party scoping, no partial-adherence gold) →
   policy-asks novelty intact. Cost reporting is total-cost, never
   token-normalized → proposal-01 normalization still novel. No
   placebo/negative-control discipline anywhere → sham-policy borrowing
   still unique.
6. **Evidence-quality caution.** B05 documents Mem0's MemGPT-on-LoCoMo
   numbers as unreproducible (no backfill path, no response to issue
   #3004). Rule restated: vendor numbers without a runnable backfill
   path are not baselines — this applies to our own claims symmetrically.
